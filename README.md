# Kaspi Parser (C# + Playwright + WinForms)

Парсер категории Kaspi Магазина с простым GUI: вставляешь ссылку на категорию,
жмёшь "Старт" — приложение собирает товары и сортирует их по количеству
отзывов (это лучший публично доступный прокси для объёма продаж — точное
число проданных штук Kaspi не показывает).

Работает только на Windows (WinForms — Windows-only UI-фреймворк).

## Установка

1. Установи .NET SDK (8 или 10, оба подойдут — в `.csproj` сейчас указан
   `net10.0-windows`, при необходимости поменяй на `net8.0-windows`):
   https://dotnet.microsoft.com/download

2. В папке проекта:

```bash
dotnet restore
dotnet build
```

3. Поставь браузеры для Playwright (один раз):

```bash
pwsh bin/Debug/net10.0-windows/playwright.ps1 install chromium
```

Если `pwsh` не установлен:

```bash
dotnet tool install --global Microsoft.Playwright.CLI
playwright install chromium
```

## Запуск

```bash
dotnet run
```

Откроется окно:
- **Ссылка на категорию** — вставь URL страницы категории Kaspi (например,
  `https://kaspi.kz/shop/c/smartphones/`)
- **Макс. страниц** — сколько страниц пагинации пролистать (по умолчанию 20)
- **Задержка (мс)** — пауза между действиями, чтобы не словить капчу/бан
  по IP (по умолчанию 1500 мс, не советую сильно уменьшать)
- **Старт** — запускает сбор, лог хода работы выводится в текстовое поле снизу
- **Открыть CSV** — становится активной после завершения, открывает папку
  с результатом и подсвечивает файл

Результат сохраняется рядом с exe-файлом как
`kaspi_top_products_ГОД-МЕСЯЦ-ДЕНЬ_ЧЧ-ММ-СС.csv`, отсортирован по убыванию
количества отзывов.

## Структура проекта

- `Program.cs` — точка входа, просто запускает форму
- `MainForm.cs` — окно приложения (поля ввода, кнопки, лог, сохранение CSV)
- `Scraper.cs` — вся логика Playwright-скрейпинга, независима от GUI

## Настройка селекторов (ОБЯЗАТЕЛЬНО при поломке)

Разметка Kaspi может поменяться в любой момент — если парсер перестал находить
товары или кнопку "Следующая":

1. Открой нужную категорию на kaspi.kz в Chrome
2. Правая кнопка мыши на карточке товара → "Просмотреть код" (Inspect)
3. Найди актуальные CSS-классы карточки, названия, цены, рейтинга, количества
   отзывов и кнопки пагинации "Следующая"
4. Подставь их в константы `SelectorProductCard`, `SelectorTitle`,
   `SelectorPrice`, `SelectorRating`, `SelectorReviews`, `SelectorNextPage`
   в начале `Scraper.cs`

Сейчас там актуальные на момент написания селекторы:
- Карточка: `.item-card`
- Название: `.item-card__name`
- Цена: `.item-card__prices-price`
- Рейтинг: `.item-card__rating`
- Отзывы: `.item-card__rating-count`
- Кнопка "Следующая": `<li class="pagination__el">Следующая →</li>`
  (недоступность — по классу `_disabled`)

## Важно

- Не уменьшай задержку слишком сильно — Kaspi может показать капчу или
  временно заблокировать IP.
- Для отслеживания скорости продаж (а не разового снимка) лучше запускать
  парсер раз в день/неделю и сравнивать прирост `ReviewsCount` между
  файлами, а не смотреть на абсолютное число.
- Скрейпинг каталога — серая юридическая зона (ToS Kaspi явного разрешения
  на это не даёт), используй аккуратно и не для коммерческой перепродажи
  данных.
